# BÀI TẬP LAB 2 - HỆ THỐNG QUẢN LÝ THƯ VIỆN

## 1. Thông tin sinh viên
- **Họ và tên:** Lê Hoàng Hữu Lộc
- **Mã sinh viên:** 1250080101
- **Lớp / Môn học:** Phát triển phần mềm hướng đối tượng (OOSD)

## 2. Mô tả bài tập
Ứng dụng Quản lý Thư viện viết bằng C# Windows Forms (.NET Framework 4.7.2). Bài Lab tập trung thiết kế giao diện các Form chức năng và xử lý sự kiện chuyển trang qua lại giữa các Form.

## 3. Các chức năng chính
- Khởi chạy màn hình chính MDI (`FrmMain`).
- Thiết kế giao diện Form: Danh mục, Sách, Độc giả, Mượn trả, Thống kê.
- Xử lý sự kiện bấm Button trên màn hình chính để mở/chuyển sang các Form chức năng tương ứng.

## 4. Hướng dẫn chạy dự án
1. Mở file `QuanLyThuVien.sln` bằng Visual Studio 2022.
2. Nhấn phím **F5** (hoặc bấm nút **Start**) để khởi chạy ứng dụng.
3. Click vào các Button trên Form chính để chuyển qua giao diện các Form khác.
